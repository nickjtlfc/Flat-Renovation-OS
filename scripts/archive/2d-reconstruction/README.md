# Historical 2D reconstruction scripts

These solvers and generators reproduce superseded Room A, Room B/WC, Room C and whole-flat reconstruction stages. They are retained for provenance and investigation, not the active workflow.

The active baseline generator is `scripts/generate_final_2d_working_baselines_v1_0.mjs`. Historical scripts may contain recorded logical paths from their original repository layout; consult the matching scope archive before running one, and do not write historical output back into an active folder.
