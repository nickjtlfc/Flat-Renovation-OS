## Entry rules

- Preserve one row per observation.
- Use a new ID for a deliberate repeat; do not overwrite the first reading.
- State the height or datum when it affects the result.
- State an open doorway, glass-door opening or other route used by the beam.
- Use `blocked`, `deferred`, `contradictory` or another explicit status rather than guessing.
- Keep raw readings unchanged during later reconciliation.
