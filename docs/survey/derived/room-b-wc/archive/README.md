# Room B/WC reconstruction archive

This folder preserves the Room B/WC pilots, evidence audits, field-reconciled v0.2 candidate, rectangular-WC v0.3 candidate, diagnostics and solver output.

The record includes the superseded 249 mm D3 return, active 136 mm return, corrected orthogonal Room B shell and human rectangular-WC decision. These are provenance, not active geometry. Historical generators are under `scripts/archive/2d-reconstruction/`.
